INSTALADOR DE INVENTARIO PARA LINUX 0.3.1
Actualización: 25 de noviembre de 2026

EJECUTAR
Abra una terminal en la carpeta del instalador y ejecute:

  bash instalar-inventario-linux.sh

El script contiene el paquete del agente. Descarga y verifica el runtime
portátil necesario; requiere conexión HTTPS y privilegios de administración
para instalar el servicio. Los pasos y resultados se muestran en pantalla
y se guardan en /var/log/inventario-telemetria/instalacion-*.log.

EFECTO DE LA EJECUCIÓN NORMAL: REINSTALACIÓN LIMPIA
La ejecución normal realiza un reset local total. Antes de detener el agente
anterior, verifica el ZIP incorporado, la integridad SHA-256 del runtime, las
conexiones HTTPS y que el montaje de destino permita ejecutar el runtime.
También solicita otra vez el código de instalación. El código INV se escribe
VISIBLE para permitir revisar lo introducido. No se guarda en este documento.
Si se solicita una clave general opcional, su entrada permanece oculta.

Tras superar esas comprobaciones, detiene el servicio anterior y elimina la
aplicación, el venv, los runtimes anteriores, la configuración y la identidad
local contenidos en estas rutas:

  /opt/inventario-telemetria
  /etc/inventario-telemetria
  /var/lib/inventario-telemetria

También sustituye la unidad telemetry-agent.service y elimina sus drop-ins
para que una configuración anterior no altere el arranque nuevo. Conserva
los registros de ejecución y la cuenta de servicio telemetry-agent.

El reset no es reversible con la identidad anterior. Si una fase posterior
falla, la instalación previa ya no queda disponible para seguir funcionando.
El instalador debe corregirse o repetirse después de resolver el diagnóstico.

PYTHON Y ARRANQUE
Se instala una copia nueva de Python portátil 3.12.16 en:

  /opt/inventario-telemetria/python-3.12.16

El servicio usa ese runtime y su venv; no depende de un Python en el directorio
personal del usuario ni reemplaza el Python del sistema. Los directorios del
runtime se normalizan a 755, con propietario root y archivos legibles y
ejecutables según corresponda, sin escritura para grupo u otros usuarios.
Antes de iniciar el servicio, se prueba Python como telemetry-agent.

Si el montaje tiene noexec o hay permisos que el instalador no puede reparar,
se detiene con un diagnóstico. No desactiva políticas de seguridad ni cambia
las opciones de montaje para forzar la ejecución. Un error 203/EXEC requiere
corregir la causa indicada y repetir la verificación o la instalación.

NUEVO REGISTRO EN EL PANEL
Al borrar la identidad local se generan un UUID y un token NUEVOS. Es necesario
introducir otra vez el código de instalación y aprobar el nuevo equipo en el
panel. La ficha anterior NO se elimina automáticamente: puede quedar otra
ficha del mismo equipo y debe identificarse y gestionarse desde el panel.
Panel: https://inventario-equipos-dyd-261117.web.app
Receptor: https://inventario-api-jryilooe3a-uc.a.run.app

COMPROBACIONES SIN REINSTALAR
Para comprobar únicamente el paquete incorporado, sin root ni acceso a red:

  bash instalar-inventario-linux.sh --check

Para revisar una instalación existente sin borrar, reiniciar ni instalar:

  bash instalar-inventario-linux.sh --verify

La verificación informa sobre el arranque, los permisos y los problemas de
ejecución, incluido 203/EXEC. La comprobación de estabilidad observa el estado
del servicio hasta 60 segundos y exige tres comprobaciones activas seguidas;
compruebe el resultado y las indicaciones mostradas antes de dar por
terminada la intervención.
